Application

Settings

Default 3D viewer

Register 3D Viewer for all supported model formats, then choose it as the default app in Windows Settings.

GLBGLTFFBXOBJSTLPLY DAE3MF3DSUSDZWRLVRML

Windows 10/11 requires the final default-app choice to be confirmed by the user. The app does not modify the protected UserChoice registry key.

Instance behavior

Choose whether opening a model reuses the current window or starts a new one. Changes apply after restarting the app.
